Для включения всех внесенных улучшений на сайте нужно добавить в index.html перед закрывающим тегом </body> строку:

<script src="improvements.js"></script>

Файл improvements.js уже добавлен в репозиторий и содержит:
1. Режим презентации.
2. Раздел Календарь.
3. Раздел Проблемы.
4. Раздел Матрица.
5. Раздел Качество данных.
6. Раздел НТС.
7. Раздел Отчет.
8. Карточку проекта по клику.
9. Готовность комплекта документов.
10. Автоматический отчет для проректора.
11. Автоматическую повестку НТС.
12. Экспертную матрицу приоритетов.

Причина отдельной инструкции: GitHub API в текущем инструменте не отдает актуальный blob SHA файла index.html в usable-виде, а без него нельзя безопасно обновить существующий index.html через contents API. Перезаписывать файл вслепую нельзя, чтобы не сломать текущую интеграцию с Google Таблицей и Apps Script.
