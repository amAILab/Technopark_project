# Панель руководителя Технопарка РГСУ - версия v2

Новая презентабельная версия сайта управленческой панели Проектного центра «Технопарк РГСУ».

## Назначение

Сайт предназначен для руководителя Проектного центра, членов НТС и проектной команды. Он показывает проекты, гранты, воронку готовности, риски, ближайшие действия и пожелания экспертного сообщества в единой управленческой системе.

Откройте в браузере:

`https://step3dlab.github.io/Technopark_project/index-next.html`

После слияния ветки и публикации GitHub Pages файл будет доступен по этому адресу. Для локальной проверки можно открыть `index-next.html` прямо из папки проекта.

## Как сделать v2 основной версией

После проверки нужно:

1. Переименовать текущий `index.html` в резервный файл, например `index-old.html`.
2. Переименовать `index-next.html` в `index.html`.
3. Оставить `styles-v2.css` и `app-v2.js` в корне проекта.
4. Закоммитить изменения в ветку `main`.
5. Проверить GitHub Pages.

## Разделы сайта

1. Обзор - первый экран, KPI, блоки внимания руководителя и НТС.
2. Проекты - карточки, таблица, фильтры, статусы, ответственные, грантовая готовность.
3. Гранты - актуальные и ранние окна, суммы, операторы, подходящие проекты, ссылки.
4. Воронка - путь проекта от идеи до отчётности по 10 этапам.
5. Пожелания НТС - форма обратной связи и лента сообщений.

## Обязательные листы таблицы

- `Реестр проектов`
- `Актуальные гранты`
- `Пакет подачи`
- `Пожелания НТС`

Лист `Пожелания НТС` уже есть в таблице. Если он будет удален, Apps Script должен создавать его через функцию `setupSheets()` или аналогичную проверку.

## Как работает форма пожеланий НТС

Форма отправляет POST-запрос в Apps Script с действием `add_nts_feedback`.

Передаются поля:

- ФИО
- роль / статус
- проект
- тип сообщения
- текст сообщения
- приоритет
- дата и время
- статус обработки: `новое`

После успешной отправки сайт показывает уведомление «Пожелание отправлено», очищает форму и добавляет сообщение в локальную ленту без перезагрузки страницы.

## Логика неопределённых данных

Если в таблице нет точной информации, сайт не придумывает значения. Он выводит:

- `требует уточнения`
- `нет точных данных`
- `ожидает заполнения`

Такие элементы выделяются мягким жёлтым бейджем.

## Публикация на GitHub Pages

1. Сохранить изменения в `main`.
2. Открыть Settings -> Pages.
3. Убедиться, что источник публикации: ветка `main`, папка `/root`.
4. Подождать обновления GitHub Pages.
5. Проверить сайт на desktop и mobile.

## Чек-лист готовности

- Первый экран выглядит как официальная управленческая панель.
- Нет формулировки «панель проректора».
- Есть «Панель руководителя Технопарка РГСУ».
- Данные проектов и грантов читаются из Google Таблицы.
- Гранты до 1 июня не удаляются, а отделяются статусом.
- Воронка показывает 10 этапов проектного пути.
- Пожелания НТС отправляются через Apps Script.
- Есть обработка ошибок и пустых состояний.
- Код содержит русские комментарии.
- Сайт адаптивен для телефона.
