# Чек-лист версии для показа

Дата подготовки: 29.04.2026

## Что проверено и усилено

- Навигация по основным разделам панели.
- Кнопки обновления данных.
- Переходы по якорям и разделам.
- Форма пожеланий НТС.
- Отправка формы НТС в актуальный Apps Script.
- Загрузка проектов из Google Sheets.
- Загрузка грантовых маршрутов из Google Sheets.
- Загрузка пожеланий НТС из Google Sheets.
- Пустые состояния, если данные временно не загружены.
- Уведомления об успешных и ошибочных действиях.
- Fallback-скрипт для старой опубликованной сборки.

## Проверка перед демонстрацией

1. Открыть сайт в режиме инкогнито:
   `https://step3dlab.github.io/Technopark_project/#nts`
2. Нажать кнопку `Обновить`.
3. Убедиться, что проекты загрузились.
4. Перейти в раздел `Проекты`.
5. Перейти в раздел `Гранты`.
6. Перейти в раздел `НТС`.
7. Отправить тестовое пожелание НТС.
8. Проверить, что запись появилась в Google Таблице.
9. Если данные не обновились сразу, подождать несколько секунд и нажать `Обновить` еще раз.

## Важное замечание

Основная актуальная ветка - `main`.

Ветка `upgrade-manager-dashboard-2026-04-27` была подстрахована файлом `script.js`, потому что похожая старая сборка могла использовать именно этот файл. Для показа лучше использовать версию из `main`.
