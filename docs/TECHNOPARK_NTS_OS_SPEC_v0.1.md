# ТЗ v0.1 — операционная система НТС Технопарка РГСУ

## Цель

Переделать сайт «Проекты Технопарка РГСУ» в рабочий dashboard для управления проектами, ресурсами, грантами и НТС.

Сайт используется не как витрина, а как операционный экран еженедельного совещания НТС: проекты + люди + часы + гранты + вопросы + голосования + решения + агент + Google Таблица.

## Навигация MVP

1. Главная
2. Ресурсы
3. Гранты
4. Проекты
5. НТС
6. Сквозной нижний чат на каждой странице

## Источник данных

Основной источник — Google Таблица.

MVP-архитектура:

```text
Frontend → Google Apps Script API → Google Sheets → Telegram/OpenClaw Agent
```

Fallback: все события сохраняются в Google Таблицу; если агент недоступен, событие попадает в `AgentQueue` со статусом `pending`.

## Приёмка MVP

MVP считается готовым, если:

1. Форма на главной пишет данные в Google Таблицу.
2. Человеко-часы считаются автоматически.
3. На странице ресурсов видны люди, компетенции и загрузка.
4. В проектах работают поиск, фильтры и виды.
5. По клику открывается паспорт проекта.
6. В паспорте есть цель, задачи, ответственный, даты, Drive-ссылка.
7. На странице грантов есть воронка и временная шкала.
8. На странице НТС можно создать пункт повестки.
9. Можно запустить голосование.
10. QR-код открывает мобильную форму голосования.
11. Голоса сохраняются в Google Таблицу.
12. Результаты видны на экране.
13. Нижний чат есть на каждой странице.
14. Сообщения чата сохраняются с контекстом.
15. События отправляются агенту или в AgentQueue.
16. При недоступности агента данные не теряются.
