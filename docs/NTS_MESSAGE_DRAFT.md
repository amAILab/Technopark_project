# Черновик сообщения для НТС / проектной команды

Дата обновления: 2026-05-09.

> Не отправлять без подтверждения Никиты.

Коллеги, добрый день.

Подготовлена рабочая панель портфеля проектов Технопарка РГСУ для подготовки к НТС и управленческим решениям.

Панель помогает быстро увидеть:

- текущий состав проектного портфеля;
- проекты, требующие внимания руководителя;
- ближайшие действия на 7 дней;
- готовность проектов к НТС и грантовым маршрутам;
- недостающие данные по проектам и материалам.

Ссылка на рабочую копию:

`https://amailab.github.io/Technopark_project/`

Просьба перед следующим обсуждением проверить по своим проектам:

1. корректность названия и краткого описания;
2. ответственного;
3. текущий статус;
4. ближайшее действие;
5. срок/дедлайн;
6. наличие материалов или ссылки на них;
7. что требуется вынести на решение руководителя или НТС.

Цель — использовать панель не как разовую презентацию, а как регулярный инструмент подготовки решений по проектам.
