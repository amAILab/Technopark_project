# Google Sheets schema v0.1 — ОС НТС Технопарка РГСУ

Документ фиксирует структуру основной Google Таблицы для сайта «Проекты Технопарка РГСУ».

Цель: сделать таблицу единой базой данных для проектов, людей, ресурсов, грантов, НТС, голосований, чата и очереди агента.

## Принцип архитектуры

```text
Frontend GitHub Pages
  → Google Apps Script Web App API
  → Google Sheets
  → Telegram/OpenClaw Agent или AgentQueue
```

Правило: любые действия пользователя сначала сохраняются в Google Таблицу. Если агент недоступен, событие не теряется, а получает статус `pending` в листе `AgentQueue`.

## Листы MVP

1. `Settings` — настройки и справочники.
2. `People` — участники, компетенции, категории, доступность.
3. `Projects` — каталог проектов.
4. `ProjectPassports` — расширенные паспорта проектов.
5. `ProjectHours` — учёт человеко-часов.
6. `Grants` — грантовая воронка.
7. `GrantTimeline` — временная шкала / диаграмма Ганта.
8. `NTSAgenda` — повестка НТС.
9. `Votes` — голосования.
10. `VoteResponses` — ответы по QR-голосованиям.
11. `ChatMessages` — нижний чат на страницах.
12. `AgentQueue` — очередь событий для Telegram/OpenClaw агента.
13. `AuditLog` — журнал изменений.

## Минимальный API Google Apps Script

### GET `/api?action=list&entity=projects`
Возвращает список сущностей: `people`, `projects`, `grants`, `agenda`, `votes`.

### GET `/api?action=get&entity=project&id=PROJECT_ID`
Возвращает одну сущность и связанный паспорт.

### POST `/api?action=create&entity=chatMessage`
Создаёт сообщение чата и событие в `AgentQueue`.

### POST `/api?action=create&entity=agendaItem`
Создаёт пункт повестки НТС.

### POST `/api?action=create&entity=vote`
Создаёт голосование по пункту НТС.

### POST `/api?action=create&entity=voteResponse`
Сохраняет голос по QR-форме.

### POST `/api?action=update&entity=project`
Обновляет проект или паспорт проекта.

## Порядок разработки

### Этап 1. Данные и архитектура

- утвердить структуру Google Таблицы;
- создать листы;
- настроить Google Apps Script;
- реализовать API чтения и записи;
- подготовить очередь `AgentQueue`.

### Этап 2. Главная и форма

- сделать стартовую страницу;
- реализовать универсальную форму;
- подключить запись в Google Таблицу;
- вывести базовую статистику.

### Этап 3. Ресурсы

- реализовать список участников;
- учёт человеко-часов;
- фильтры;
- расчёт свободного времени.

### Этап 4. Проекты

- реализовать каталог проектов;
- фильтры по лабораториям;
- виды: плитки, таблица, список;
- паспорта проектов;
- индикатор заполненности.

### Этап 5. Гранты

- реализовать грантовую воронку;
- карточки грантов;
- диаграмму Ганта;
- связи грантов с проектами.

### Этап 6. НТС и голосование

- повестка;
- запуск голосований;
- QR-код;
- мобильная форма;
- результаты;
- фиксация решений.

### Этап 7. Чат и агент

- нижний чат на всех страницах;
- сохранение заметок;
- отправка событий агенту;
- очередь необработанных событий;
- подготовка данных для протокола.

## Короткая формулировка задачи для разработчика

Нужно переделать текущий сайт «Проекты Технопарка РГСУ» в рабочий dashboard для управления проектами, ресурсами, грантами и НТС.

Основная база данных — Google Таблица.

Сайт должен позволять участникам оставлять вопросы, регистрировать доступное время, смотреть проекты, открывать паспорта, учитывать человеко-часы, вести грантовую воронку, формировать повестку НТС, запускать QR-голосования и отправлять события агенту Telegram/OpenClaw.

Дизайн — минималистичный, понятный, удобный для показа на совещаниях.

Главная концепция: сайт становится операционной системой НТС Технопарка:

```text
Проекты + люди + часы + гранты + вопросы + голосования + решения + агент + Google Таблица
```
